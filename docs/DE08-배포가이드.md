## 3. 빌드

### 3.1 프로덕션 빌드

```bash
# 환경 변수 설정
export VITE_SERVER_API=https://v2.allbarlawbiz.com
export VITE_AI_SUMMARY_SERVER_API=https://ai.allbarlaw.com

# 빌드 실행
npm run build
```

## 4. Netlify 배포

### 4.1 설정

**netlify.toml**:
```toml
[build]
  command = "npm run build"
  publish = "dist"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```

### 4.2 환경 변수 (Netlify Dashboard)

```
VITE_SERVER_API=https://v2.allbarlawbiz.com
VITE_AI_SUMMARY_SERVER_API=https://ai.allbarlaw.com
```

---

## 5. 정적 서버 배포

### 5.1 Nginx 설정

```nginx
server {
    listen 80;
    server_name admin.allbarlaw.com;
    root /var/www/allbarlaw-admin/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```
