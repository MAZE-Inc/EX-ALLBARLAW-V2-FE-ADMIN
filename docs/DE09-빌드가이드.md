# DE09. 빌드/배포 패키지 가이드

## 1. 개요

본 문서는 EX-ALLBARLAW-V2-FE-ADMIN 프로젝트의 빌드 방법 및 산출물에 대해 설명합니다.

---

## 2. 빌드 도구

- **Vite**: 6.2.0
- **TypeScript**: 5.7.2

---

## 3. 빌드 명령어

### 3.1 기본 빌드

```bash
npm run build
# 내부: tsc -b && vite build
```

### 3.2 빌드 과정

```
1. TypeScript 컴파일 (tsc -b)
2. Vite 빌드
   ├── 코드 번들링
   ├── 트리 쉐이킹
   ├── 코드 스플리팅
   ├── 미니파이
   └── 에셋 최적화
```

---

## 4. 빌드 산출물

### 4.1 위치

```
dist/
├── index.html
├── assets/
│   ├── index-[hash].js
│   ├── index-[hash].css
│   ├── vendor-[hash].js
│   └── [에셋 파일들]
```

### 4.2 권장 번들 크기

| 항목 | 권장 크기 |
|------|----------|
| 메인 번들 (JS) | < 300KB (gzip) |
| Ant Design 포함 | < 400KB (gzip) |
| 메인 스타일 (CSS) | < 100KB (gzip) |

---

## 5. 빌드 설정

### 5.1 vite.config.ts

```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import svgr from 'vite-plugin-svgr'

export default defineConfig({
  plugins: [svgr(), react()],
  resolve: {
    alias: [{ find: '@', replacement: '/src' }],
  },
  build: {
    target: 'es2020',
    outDir: 'dist',
    sourcemap: false,
    chunkSizeWarningLimit: 500,
    rollupOptions: {
      output: {
        manualChunks: {
          vendor: ['react', 'react-dom', 'react-router-dom'],
          antd: ['antd', '@ant-design/icons'],
        },
      },
    },
  },
})
```

## 6. 빌드 검증

### 6.1 빌드 미리보기

```bash
npm run preview
# http://localhost:4173
```

### 6.2 빌드 크기 확인

```bash
du -sh dist/
ls -lh dist/assets/
```

---

## 7. 빌드 문제 해결

### 7.1 메모리 부족

```bash
export NODE_OPTIONS="--max-old-space-size=4096"
npm run build
```

### 7.2 캐시 정리

```bash
rm -rf node_modules/.vite
npm run build
```
