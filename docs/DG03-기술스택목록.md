## 9. 기술 선정 사유

### 9.1 React 18 (vs React 19 in FE)
- 안정성 우선: 관리자 페이지는 안정성 중시
- Ant Design 호환성: React 18과 최적 호환

### 9.2 Ant Design
- 풍부한 관리자 UI 컴포넌트
- 테이블, 폼, 모달 등 관리 기능에 최적화
- 일관된 디자인 시스템

### 9.3 Toast UI Editor
- 한국어 친화적 에디터
- 마크다운/WYSIWYG 지원
- 이미지 업로드 및 리사이징

### 9.4 xlsx
- 엑셀 데이터 내보내기 기능
- 관리자 리포트 생성
