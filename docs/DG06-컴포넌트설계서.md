# DG06. SW 컴포넌트(모듈/클래스) 상세 설계서

## 1. 개요

본 문서는 EX-ALLBARLAW-V2-FE-ADMIN 프로젝트의 React 컴포넌트 구조와 설계를 정의합니다.

---

## 2. 컴포넌트 분류 체계

### 2.1 컴포넌트 계층 구조
```
src/
├── components/          # 재사용 가능한 공통 컴포넌트
├── pages/              # 페이지 레벨 컴포넌트
├── hooks/              # 커스텀 훅
├── contexts/           # React Context
└── container/          # 비즈니스 로직 컨테이너
```

## 7. 컴포넌트 설계 원칙

### 7.1 Ant Design 활용
- Table, Form, Modal, Button 등 Ant Design 컴포넌트 기반
- 커스터마이징은 최소화하여 일관성 유지

### 7.2 명명 규칙
- **파일명**: PascalCase (예: `BlogList.tsx`)
- **폴더명**: camelCase (예: `blogList/`)
- **페이지 접미사**: Page 또는 Layout 사용
