## 4. 컴포넌트 폴더 구조 표준

```
componentName/
├── ComponentName.tsx        # 컴포넌트 파일
├── ComponentName.module.scss # 스타일 파일
└── index.ts                 # 내보내기 (선택)
```

---

## 5. 폴더 명명 규칙

| 유형 | 규칙 | 예시 |
|------|------|------|
| 컴포넌트 폴더 | camelCase | `blogItem/` |
| 컴포넌트 파일 | PascalCase | `BlogItem.tsx` |
| 페이지 폴더 | camelCase | `blogList/` |
| 페이지 파일 | PascalCase | `BlogList.tsx` |
| 서비스 파일 | camelCase + Service | `blogService.ts` |
