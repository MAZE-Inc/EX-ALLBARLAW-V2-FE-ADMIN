## 3. 상세 기능 설계

### 3.1 F-A-001 관리자 로그인

#### 3.1.1 기능 설명
- 관리자 아이디/비밀번호 인증
- 세션 기반 로그인 유지

#### 3.1.2 화면 흐름
```
로그인 화면 → 인증 → 관리자 대시보드
```

#### 3.1.3 입력 항목
| 항목 | 필수 | 유효성 검사 |
|------|------|-------------|
| 아이디 | O | 필수 입력 |
| 비밀번호 | O | 필수 입력 |

#### 3.1.4 관련 API
- `POST /admin/auth/login` - 관리자 로그인

---

### 3.2 F-L-003 변호사 승인/반려

#### 3.2.1 기능 설명
- 신규 가입 변호사 승인/반려 처리
- 반려 시 사유 입력

#### 3.2.2 화면 흐름
```
변호사 목록 → 상세 조회 → 승인/반려 모달 → 처리 완료
```

#### 3.2.3 처리 상태
| 상태 | 설명 |
|------|------|
| 대기 | 승인 대기 상태 |
| 승인 | 활동 가능 |
| 반려 | 가입 거부 |
| 정지 | 활동 정지 |

#### 3.2.4 관련 API
- `PATCH /admin/lawyers/:id/approve` - 변호사 승인
- `PATCH /admin/lawyers/:id/reject` - 변호사 반려

---

### 3.3 F-C-003 블로그 작성

#### 3.3.1 기능 설명
- Toast UI Editor 기반 블로그 작성
- 이미지 업로드
- 카테고리 설정

#### 3.3.2 화면 흐름
```
블로그 목록 → 작성 버튼 → 에디터 → 저장/발행
```

#### 3.3.3 입력 항목
| 항목 | 필수 | 설명 |
|------|------|------|
| 제목 | O | 블로그 제목 |
| 카테고리 | O | 법률 분야 |
| 변호사 | O | 작성자 변호사 선택 |
| 본문 | O | Rich Text 내용 |
| 대표 이미지 | X | 썸네일 |
| 태그 | X | 관련 태그 |

#### 3.3.4 관련 API
- `POST /admin/blog-cases` - 블로그 생성
- `POST /upload` - 이미지 업로드

---

### 3.4 F-CT-004 카테고리 순서 변경

#### 3.4.1 기능 설명
- 드래그 앤 드롭으로 카테고리 순서 변경
- @dnd-kit 라이브러리 활용

#### 3.4.2 화면 흐름
```
카테고리 관리 → 드래그 → 순서 변경 → 저장
```

#### 3.4.3 관련 API
- `PATCH /admin/categories/order` - 순서 업데이트

---

### 3.5 F-AD-001 메인 배너 관리

#### 3.5.1 기능 설명
- 메인 페이지 슬라이더 배너 관리
- 배너 이미지, 링크, 노출 순서 설정

#### 3.5.2 입력 항목
| 항목 | 필수 | 설명 |
|------|------|------|
| 제목 | O | 배너 제목 |
| 이미지 (PC) | O | PC 버전 이미지 |
| 이미지 (Mobile) | O | 모바일 버전 이미지 |
| 링크 URL | X | 클릭 시 이동 URL |
| 노출 순서 | O | 슬라이더 순서 |
| 노출 여부 | O | 활성/비활성 |
| 노출 기간 | X | 시작일/종료일 |

#### 3.5.3 관련 API
- `GET /admin/banners/main` - 배너 목록
- `POST /admin/banners/main` - 배너 생성
- `PUT /admin/banners/main/:id` - 배너 수정
- `DELETE /admin/banners/main/:id` - 배너 삭제
