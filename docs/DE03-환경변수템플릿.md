# DE03. 설정 파일/환경변수 템플릿

## 1. 개요

본 문서는 EX-ALLBARLAW-V2-FE-ADMIN 프로젝트의 환경 변수 및 설정 파일 템플릿을 정의합니다.

---

## 2. 환경 변수 (.env)

### 2.1 환경 변수 템플릿 (.env.example)

```bash
# ===========================================
# API 서버 설정
# ===========================================

# 백엔드 API 서버 URL
# 운영: https://v2.allbarlawbiz.com
# 테스트: https://test.allbarlawbiz.com
# 로컬: http://localhost:3000
VITE_SERVER_API=https://test.allbarlawbiz.com

# AI 요약 서버 URL
VITE_AI_SUMMARY_SERVER_API=https://ai.allbarlaw.com
```

### 2.2 환경별 설정

#### 개발 환경 (.env.development)
```bash
VITE_SERVER_API=http://localhost:3000
VITE_AI_SUMMARY_SERVER_API=https://ai.allbarlaw.com
```

#### 테스트 환경 (.env.staging)
```bash
VITE_SERVER_API=https://test.allbarlawbiz.com
VITE_AI_SUMMARY_SERVER_API=https://ai.allbarlaw.com
```

#### 운영 환경 (.env.production)
```bash
VITE_SERVER_API=https://v2.allbarlawbiz.com
VITE_AI_SUMMARY_SERVER_API=https://ai.allbarlaw.com
```

### 2.3 환경 변수 설명

| 변수명 | 설명 | 필수 |
|--------|------|------|
| VITE_SERVER_API | 백엔드 API 서버 URL | O |
| VITE_AI_SUMMARY_SERVER_API | AI 요약 서버 URL | O |
