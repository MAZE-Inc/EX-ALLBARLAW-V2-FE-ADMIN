## 3. 프로젝트 설정

### 3.1 저장소 클론

```bash
git clone https://github.com/your-org/EX-ALLBARLAW-V2-FE-ADMIN.git
cd EX-ALLBARLAW-V2-FE-ADMIN
```

### 3.2 의존성 설치

```bash
npm install
# 또는
npm ci
```

### 3.3 환경 변수 설정

```bash
cp .env.example .env
```

**.env 파일 설정**:
```bash
VITE_SERVER_API=https://test.allbarlawbiz.com
VITE_AI_SUMMARY_SERVER_API=https://ai.allbarlaw.com
```

### 3.4 Git 훅 설정

```bash
npm run prepare
```

---

## 4. 개발 서버 실행

### 4.1 개발 서버 시작

```bash
npm run dev
```

**접속 URL**: http://localhost:5174

> **참고**: 관리자 프로젝트는 포트 5174를 사용합니다 (FE: 5173)

### 4.2 개발 서버 옵션

```bash
# 특정 포트로 실행
npm run dev -- --port 3001

# 네트워크 접근 허용
npm run dev -- --host
```

## 7. 프로젝트 구조 이해

### 7.1 주요 디렉토리

```
src/
├── components/     # Ant Design 기반 공통 컴포넌트
├── pages/          # 관리자 페이지
├── services/       # API 서비스
├── hooks/          # 커스텀 훅
├── types/          # TypeScript 타입
└── styles/         # 글로벌 스타일
```

### 7.2 경로 별칭

```typescript
// @ = src/
import { Header } from '@/components/header'
```
